# Courier Tracker

A React + Vite app for tracking couriers and deliveries.

## Features
- Dashboard counts per status (click to filter)
- Search by tracking number, sender/recipient, courier, or city
- Shipment detail with progress bar and tracking timeline
- Add status updates to a shipment
- Create and delete shipments
- Data saved in the browser (localStorage), with sample data on first load

## Run
npm install
npm run dev

Build for production: npm run build
